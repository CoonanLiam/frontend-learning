Einführung in HTML

HTML (Hyper Text Markup Language) ist das Skelett jeder Webseite. Es gibt dem Inhalt eine logische Struktur.

Aufbau eines HTML-Dokuments

!DOCTYPE html definiert den Dokumenttyp als HTML5.

Der head-Bereich enthält unsichtbare Metadaten, während der body alles Sichtbare beherbergt.

Wichtige Tags & Listen

  • <strong> macht den Text fett gedruckt.
  • <em> macht den Text kursiv (betont).
  • <br> erzwingt einen Zeilenumbruch.
  • <a> wird für Links verwendet.
  • <img> zeigt Bilder an.

Anleitung: Erste Schritte

  1. Neue Datei mit der Endung .html erstellen.
  2. !DOCTYPE html am Anfang schreiben.
  3. html-Tag öffnen.
  4. head-Bereich mit title erstellen.
  5. body-Bereich für sichtbaren Inhalt erstellen.
  6. Datei speichern und im Browser öffnen.

Der Unterschied: ul ist ungeordnet (Punkte), ol ist geordnet (Nummern).

Einführung in CSS

CSS bestimmt das Aussehen. Eine CSS-Regel besteht aus Selektor, Eigenschaft und Wert.

p { color: blue; }

p = Selektor | color = Eigenschaft | blue = Wert
